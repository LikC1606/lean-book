# 第 21 章　教育、科研与更多领域

> 本章目标：了解 Lean 在教学、硬件验证、科研协作等领域的应用，为你规划"Lean 能力"的更多用武之地。

## 21.1 教育：游戏化的证明学习

### 自然数游戏（Natural Number Game）

[adam.math.hhu.de](https://adam.math.hhu.de/)——Kevin Buzzard 与 Jon Eugster 制作的网页游戏，是当今最受欢迎的 Lean 入门途径：

- **玩法**：从定义自然数开始，一关一个定理（加法交换律、结合律、乘法分配律……），用策略通关；
- **世界**：Tutorial World → Addition World → Multiplication World → Power World → Inequality World……还有"高级分区"（算法世界、集合论世界）；
- **成就**：通关 ≈ 亲手重建了皮亚诺算术——你会深刻理解"自然数的性质不是公理堆出来的，而是从定义长出来的"。

强烈建议所有读者花几个晚上通关基础世界——比读十页书更能建立证明直觉。

### Lean Game Server

同一个平台上有更多游戏：**集合论游戏**（Set Theory Game）、**Robo 逻辑游戏**……适合不同主题的游戏化学习。

### 大学课堂里的 Lean

- Fordham 大学《Math 2001》（配套教材 *The Mechanics of Proof*）：本科生第一门"证明课"就用 Lean 教——把"写完证明自己都不确定对不对"变成"电脑立刻告诉你"；
- 帝国理工、CMU、阿姆斯特丹自由大学等均有 Lean 课程；
- 教学经验总结：Lean 的即时反馈（Infoview）让"证明"从黑箱作业变成可迭代的手艺，**学生的挫败感显著下降**。

## 21.2 硬件验证：从电路到芯片

第 19 章我们写了玩具电路 DSL，真实的硬件验证走得更远：

- **电路等价性验证**：两个电路描述是否功能相同（对 ECO 工程变更检查至关重要）；
- **ISA 语义**：RISC-V 指令集的形式化语义（Lean 中有 Sail 风格的模型项目）——验证"编译器后端生成的指令流确实实现了源语义"；
- **zkVM 电路**：区块链的零知识虚拟机电路用 Lean 验证（与第 16 章 ArkLib 生态呼应）。

硬件领域历来是形式化验证最成熟的市场（Intel 因 FDIV bug 损失 4.75 亿美元后大规模投入），Lean 正在加入这个传统上以 ACL2/HOL 为主的战场。

## 21.3 科研协作的新范式：Blueprint 模式

大规模形式化项目（如费马大定理 FLT、PFR、多项式方法）发明了独特的协作流程：

```
论文（人类数学）
   ↓ 人工拆解
Blueprint（蓝图）：把证明拆成几百个带依赖关系的小引理
   ↓ 社区认领
Lean 代码：每人证一小块，内核保证拼起来严丝合缝
   ↓ 可视化
依赖图网站：绿色 = 已形式化，蓝色 = 待认领
```

妙处：**数学家和 Lean 工程师可以并行工作**——数学家负责"拆得对"（蓝图保持数学忠实），社区负责"证得完"（Lean 内核把关）。陶哲轩评价：Lean 让数学第一次实现了"开源软件式的大规模协作"。

如果你完成了本书的学习，**参与一个 blueprint 项目的引理认领**是绝佳的进阶方式——真实研究、有人指导、贡献永存。

## 21.4 文档与写作：Verso

Lean 社区连"写书"都用 Lean 解决：**Verso** 是 Lean 原生的文档/著书平台：

- 官方语言参考、FPIL、TPIL 等教材全部用 Verso 写成；
- 书里的 Lean 代码块是**活的**：构建时真的编译，保证书中的例子永不过时；
- 可以生成网站和 PDF。

如果你未来想写 Lean 教程或文档，Verso 是首选工具链。

## 21.5 其他值得知道的方向

- **量子计算**：量子电路/协议的形式化（mathlib 的线性代数正好派用场）；
- **生物学/医学**：生化反应网络、临床协议的建模验证（早期探索）；
- **法律与合规**：把法规写成可执行 + 可验证的规则（"计算法律"领域开始关注证明器）；
- **航空航天**：NASA 形式化方法 symposium 已将 Lean 列为重点；安全攸关软件的认证标准（DO-178C）与形式化证明天然契合；
- **密码标准**：NIST 后量子密码标准的参考实现验证（Aeneas/SymCrypt 路线的延伸）。

## 21.7 本章小结

- 教育：自然数游戏 + 大学课程，Lean 正在改变"证明教学"；
- 硬件：电路等价、ISA 语义、zkVM——形式化验证的传统高地，Lean 已入场；
- Blueprint 模式让前沿数学的大规模形式化协作成为现实；
- Verso 让"书中的代码永远可运行"；
- 量子、法律、航空、医学……版图还在扩张。

## 练习

1. 通关自然数游戏的 Addition World（大约 2–3 小时），记录哪一关让你卡最久、为什么；
2. 访问 FLT 项目的 blueprint 网站，找一个"蓝色"（未形式化）的小引理，评估自己离解决它还差什么；
3. 用 Verso 的模板仓库生成一本"迷你书"，写一页关于你最近证明的定理；
4. （讨论）Blueprint 模式解决了大规模形式化的哪些协作难题？类比开源软件，"code review"对应其中的什么环节？
