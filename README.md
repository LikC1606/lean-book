# Lean 4 漫游指南

**一本写给普通程序员和数学爱好者的 Lean 4 中文入门书**

---

## 这本书是什么？

Lean 4 是一门独特的语言：它既是一门**现代函数式编程语言**，又是一个**交互式定理证明器**。你可以用它写网站后端、写编译器、验证 AWS 的授权系统、证明数学定理、甚至让 AI 帮你自动证明定理。

市面上关于 Lean 4 的英文资料不少（如 *Theorem Proving in Lean 4*、*Functional Programming in Lean*、*Mathematics in Lean*），但中文系统教程稀缺，而且许多资料对初学者来说相当硬核。本书的目标是：

1. **用大白话讲清楚** Lean 4 的核心概念，拒绝堆砌术语；
2. **覆盖 Lean 4 的全部应用领域**——从编程、数学证明，到软件验证、密码学、AI 辅助证明；
3. **所有代码示例都可以直接运行**，边读边动手。

## 这本书适合谁？

- 会任何一门编程语言（Python / JavaScript / Java 都行）的程序员；
- 对形式化数学好奇的数学系学生或爱好者；
- 想了解"AI 证明数学定理"背后技术的人；
- 做软件验证、密码学、区块链工程的工程师。

**不需要**你先懂函数式编程，**不需要**你是数学专业，**更不需要**你以前接触过定理证明器。

## 怎么读这本书？

- **线性阅读**是最稳妥的方式，每一章都建立在前面章节的基础上；
- 如果你只想学**编程**，读完第 1–7 章即可；
- 如果你只想学**数学证明**，读第 1–3 章后直接跳到第 8 章；
- 如果你关心**工业应用**（软件验证、密码学），第 1–3 章 + 第 14–16 章是最短路径；
- 每一章末尾都有**练习**和**延伸阅读**，建议动手完成。

## 在线运行 Lean 4

不想装环境？没问题。打开 [Lean 4 Web Playground](https://live.lean-lang.org/) 就能在浏览器里运行书中绝大部分示例。当然，我们强烈建议按照第 2 章安装本地环境，体验会好得多。

## 关于版本

本书基于 2025 年的 Lean 4 稳定版（Lean 4.x toolchain，由 Lean FRO 维护）。Lean 4 仍在快速演进，个别细节可能随版本变化，但核心思想是稳定的。
